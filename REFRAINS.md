# REFRAINS — running motifs (the account's memory of echoes)
*Each refrain: what it is, where it runs, the law of using it.*
- **The Friday burgers** — Dad's promise, counted by JARVIS ("five"). Seeded Ch.1; broken Ch.2; payoff owed at the return era. Law: behavior only, never announced.
- **The weird rock** — Ch.1 goodbye bargain ("bring me something weird from the desert" / "a rock" / "a weird rock"). Unpaid. Heavy. Reserved for the homecoming.
- **The second milk glass** — habit from the years of someone across the counter. Ch.1 poured-and-unwashed; Ch.2 one glass only. Grief measured in glassware.
- **The lamp** — small, cold, steady; set by Tony "so the room never goes dark on you." Rule: earned whispers only, rotated, never templated.
- **The pencils** — stress-only slips (TK seed State 1–2). Ch.2 twice (jar rattle; locker pen). NEVER named, NEVER noticed by him.
- **Rhonda's pudding / the red stools** — the Thursday place; beauty-as-weather in a ketchup-bottle economy.
- **The uncloseable book** — broken-spine geography book, open to Kunar. Nobody in the house closes it.
